Project


Project: Ar Mini-Project
Description : การพัฒนาแอปพลิเคชันสื่อการเรียนรู้เชิงปฏิสัมพันธ์ผ่านเทคโนโลยีความจริงเสริม (Augmented Reality - AR) ที่ถ่ายทอดโครงสร้างทางกายวิภาคศาสตร์ของระบบทางเดินหายใจและปอดมนุษย์ในรูปแบบ 3 มิติ ผู้เรียนสามารถจำลองการหมุนสำรวจโมเดล สลับมุมมองภาพรวมได้ 3 มิติ ได้แก่ โครงสร้างปอดภายนอก (Full Lung), ระบบท่อทางเดินหายใจ (Airways) และมุมมองโปร่งใส (X-Ray) พร้อมทั้งเจาะลึกองค์ประกอบสำคัญเฉพาะจุดผ่านจุดการเรียนรู้ (Pin 1-3) ประกอบด้วย ถุงลมปอด (Alveoli), แขนงหลอดลมและกล้ามเนื้อเรียบ (Bronchi & Smooth Muscle) และกระดูกอ่อนหลอดลม (Tracheal Cartilage) รวมถึงมีระบบสื่อวิดีโอเสริมการฟัง (Listening Session) และแบบประเมินความรู้แบบปรนัย (Quiz Session) พร้อมระบบคำใบ้และสรุปผลคะแนนแบบเรียลไทม์
วัตถุประสงค์: เพื่อพัฒนาสื่อการเรียนรู้ด้านกายวิภาคศาสตร์ระบบทางเดินหายใจที่ช่วยให้เห็นภาพเชิงลึก 3 มิติได้ชัดเจนกว่าภาพประกอบในตำราเรียน 2 มิติเพื่อเปิดโอกาสให้ผู้เรียนสามารถสำรวจความสัมพันธ์ของโครงสร้างปอด ทั้งภาพรวมภายนอก ระบบทางเดินหายใจ และองค์ประกอบระดับเซลล์/เนื้อเยื่อเฉพาะจุดได้แบบ Interactiveเพื่อเสริมสร้างกระบวนการเรียนรู้ด้วยตนเองผ่านลำดับขั้น "สำรวจ, รับชม/รับฟัง, ประเมินผล" (Explore, Listen, and Quiz) ที่มีระบบติดตามความคืบหน้าเพื่อวัดผลสัมฤทธิ์ทางการเรียนรู้ของผู้ใช้งานผ่านระบบแบบทดสอบพร้อมข้อเสนอแนะทันที (Immediate Feedback) ช่วยเพิ่มความเข้าใจในหน้าที่ของอวัยวะแต่ละส่วน
